# sprint7-telecom-analysis

Objetivo del proyecto: identificar patrones de uso, detectar comportamientos atípicos y comprender qué segmentos de clientes muestran necesidades diferenciadas, con el fin de optimizar la oferta comercial y mejorar la experiencia del usuario.
Datasets utilizados: plans.csv, users_latam.csv y usage.csv

Etapas de análisis:
1. Carga y exploración de datasets
2. Identificación de problemas de datos
3. Limpieza de datos
4. Revisión de medidas clave
5. Visualización y outliers
6. Segmentación de clientes
7. Insight ejecutivo
